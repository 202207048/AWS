# AWS

## 약속 장소 판사

참여자의 출발역을 바탕으로 서울·수도권 주요 30개 역 중 공평한 약속 장소를 추천하는 모바일 우선 React 앱입니다.

### 실행

```bash
npm install
npm run dev
```

Gemini 판결문을 사용하려면 `.env.example`을 `.env`로 복사한 뒤 키를 입력합니다.

```env
VITE_GEMINI_API_KEY=발급받은_키
```

키가 없거나 API 호출이 실패하면 기본 템플릿 판결문이 자동으로 표시됩니다.

### 계산 기준

- 예상 이동시간: 직선거리(km) × 2.5분 + 기본 10분
- 공평 점수: 최대 이동시간 × 0.7 + (최대 이동시간 - 최소 이동시간) × 0.3
- 30개 후보역을 모두 계산한 뒤 점수가 낮은 상위 3개를 표시합니다.

### 명령어

- `npm run dev`: 개발 서버
- `npm run build`: 배포용 빌드
- `npm test`: 계산 및 대체 판결문 테스트

> `VITE_` 환경 변수는 브라우저 번들에 포함됩니다. 이 앱은 요구사항대로 백엔드 없이 동작하므로, Gemini 키에는 API 제한과 사용량 제한을 설정해 사용하세요.
