# 최종 점검 요청 (제출 14:50)

`main`에 모든 기능이 합쳐졌습니다. 각자 아래만 해 주세요.

```bash
git checkout main
git pull origin main
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고 확인:

1. 예시 불러오기 → 출발역 채우기 (AI 키가 없으면 "직접 선택" 안내가 정상)
2. 빈 칸은 역 선택 또는 "주소·장소로 찾기"로 채우기
3. 목적 1·2·3순위, 약속 시간 입력 → 공평한 장소 판결하기
4. 기준 토글(가장 먼 사람 / 전체 균형), 기존 방식 비교, 출발 시각, 판결문, 지도와 네이버·카카오 링크

이상한 점은 커밋 메시지 대신 개발1에게 바로 말해 주세요. 발표 질문 대비는 `docs/CRITERIA.md`, 발표 자료는 `STATUS.md`를 보세요.
